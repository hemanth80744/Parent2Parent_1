# Parent2Parent

## 📌 Overview
The main purpose of this application is to help users enquire about school details without directly contacting school management. Instead, users can connect with parents whose children are already studying in that school. This helps in getting genuine and real information about the school.

---

## 🛠️ Technologies Used
- C#
- ASP.NET Core Web API
- HTML, CSS, TypeScript
- Angular 18
- MS SQL Server

---

## ⚙️ Application Flow
1. User opens the website  
2. If the user is new, they can register and then log in  
3. The user searches for a school and gets a list of parents whose children are studying in that school  
4. The user sends a request to connect with a parent, and the parent can accept it  
5. Once accepted, the chat feature is unlocked  
6. Parents can message each other and share information
